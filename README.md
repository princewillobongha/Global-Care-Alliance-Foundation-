# Global Care Alliance Foundation

Source snapshot exported from AppDeploy app `global-care-alliance-foundation-tn70ne`.

Live site: https://global-care-alliance-foundation-tn70ne.v2.appdeploy.ai/

Tagline: Uniting Generosity. Transforming Lives.

## Stack
React 19, Vite 6, TypeScript, Tailwind CSS, AppDeploy backend SDK.

## Important operating status
- Donation payments are not active.
- Patient applications are not open.
- The website does not claim unverified registration, tax status, partners, leadership, testimonials, or impact statistics.
- Admin sign-in is restricted to the configured administrator email in the backend.

## Development
```bash
npm install
npm run dev
```

The original logo is served as an AppDeploy resource at `public/resources/global-care-alliance-logo.png`; include that asset when deploying outside AppDeploy.
